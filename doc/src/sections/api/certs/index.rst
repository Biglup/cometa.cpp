Certificates
============

Certificates register and deregister stake credentials, delegate stake and voting power,
manage pools, and authorize governance participants. The reference includes historical
certificate forms for decoding older transactions. Use TransactionBuilder for operations
that also require deposits or refunds to be balanced.
