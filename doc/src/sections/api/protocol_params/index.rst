Protocol Parameters
===================

Protocol parameters determine transaction fees, deposits, size limits, execution prices,
and governance thresholds. Fetch current values from the target network before building
transactions. ProtocolParamUpdate represents proposed changes, while ProtocolParameters
represents the current settings.
