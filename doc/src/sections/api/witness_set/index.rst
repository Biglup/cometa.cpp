Witness Set
===========

Witnesses authorize and validate a transaction. WitnessSet groups verification-key
signatures, bootstrap witnesses, native and Plutus scripts, datums, and redeemers. A
redeemer identifies its script purpose and ledger index and carries data and an
execution budget.
