Cometa.cpp
==========

Cometa.cpp provides C++17 value types backed by cardano-c. Native memory management
is automatic. This initial implementation includes hashes, credentials, and asset
names, execution budgets, protocol versions, and slot/time utilities; transaction construction and network providers will follow after API review.
